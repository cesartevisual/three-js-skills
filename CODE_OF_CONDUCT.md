# Code of conduct

We welcome contributors of all backgrounds and experience levels. Help make this project a place where people can ask questions, learn, and disagree respectfully.

## Expected behavior

- Critique ideas and code with specific, constructive feedback.
- Respect differing experience, viewpoints, and personal boundaries.
- Credit others' work and protect personal and confidential information.
- Accept corrections and keep discussions focused on the project.

Harassment, threats, discriminatory abuse, unwanted sexual attention, publishing private information without permission, and repeated disruptive behavior are not acceptable.

## Scope and moderation

These standards apply to project issues, pull requests, reviews, and other project-managed spaces. Maintainers may remove inappropriate content, pause discussions, or limit participation. Responses should reflect severity and repetition; threats or serious harassment may warrant immediate removal.

## Reporting

This repository and its issues are public. For a non-sensitive moderation request, open an issue and ask a repository administrator to review it. Do not include personal details or sensitive evidence in public issues.

For a confidential concern, use an existing private contact channel with a repository administrator. If none is available, request a private contact method without disclosing the concern's details. If the concern involves a maintainer, contact another administrator when available. GitHub's platform reporting tools are also available for violations of its policies.

A dedicated confidential conduct-reporting contact has not yet been published. Until one is provided, use the contact-request process above. Do not use the security vulnerability form for conduct concerns. No response-time or confidentiality guarantee beyond the actual reporting channel is promised.
